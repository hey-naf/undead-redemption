## About the Game

You are a zombie who got caught. The mob is coming - pitchforks, shovels, machetes -
and you have to run. Survive as long as you can.

A 2D top-down survival game written in Python with pygame. Every hunter carries a
different weapon, and each weapon has its own speed and reach: a knife is fast but
short, a pitchfork is slow but dangerous from far away.

## How to Play

| Key | Action |
| --- | --- |
| `W` `A` `S` `D` / Arrow keys | Move the zombie |
| `R` | Restart after game over |
| `Esc` | Quit |

Stay out of reach of the weapons. When a hunter gets close enough to hit you, the
run ends and your survival time becomes your final score.
